    Installation instructions

    Install Python 3.11 and Ollama using their official installers. Run the following commands in a terminal; use python3 instead of python on macOS if needed.

    python -m pip install faster-whisper==1.2.1
ollama pull qwen2.5:3b
ollama pull gemma3:4b

    Start Ollama and check dependencies again. The first transcription may download a Whisper model.
